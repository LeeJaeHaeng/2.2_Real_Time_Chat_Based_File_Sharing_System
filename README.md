# Real-Time Chat-Based File Sharing System

## 프로젝트 개요
본 프로젝트는 자바(Java)로 개발된 실시간 채팅 기반 파일 공유 시스템입니다. 사용자들은 실시간으로 서로 메시지를 주고받을 수 있으며, 채팅 인터페이스를 통해 파일을 전송할 수 있습니다.

## 주요 기능
- **실시간 채팅**: 다수의 클라이언트 간 실시간 텍스트 메시징
- **파일 공유**: 채팅 중 파일 업로드 및 다운로드 기능
- **사용자 인증**: 사용자 식별 및 관리
- **연결 관리**: 서버-클라이언트 연결 및 다중 클라이언트 지원

## 기술 스택
- **개발 환경**: Eclipse IDE
- **언어**: Java
- **네트워크**: Socket Programming (java.net)
- **동시성 처리**: Multi-threading
- **사용자 인터페이스**: Java Swing/AWT
- **파일 입출력**: Java I/O

## 시스템 구성
1. **서버 컴포넌트**: 
   - 다중 클라이언트 연결 관리
   - 메시지 브로드캐스팅
   - 파일 전송 중계

2. **클라이언트 컴포넌트**:
   - 채팅 인터페이스
   - 파일 전송 인터페이스
   - 사용자 인증

## 설치 및 실행 방법
1. 이 저장소를 클론합니다.
   ```
   git clone https://github.com/LeeJaeHaeng/2.2Real_Time_Chat_Based_File_Sharing_System.git
   ```
2. Eclipse IDE를 실행하고 File > Import > Existing Projects into Workspace를 선택합니다.
3. 클론한 프로젝트 디렉토리를 선택하고 Finish를 클릭합니다.
4. 서버 애플리케이션을 먼저 실행합니다.
5. 클라이언트 애플리케이션을 여러 인스턴스로 실행하여 채팅 및 파일 공유 기능을 테스트합니다.

## 사용 방법
1. 클라이언트 애플리케이션 실행 시 사용자 이름 입력
2. 채팅 메시지 작성 및 전송
3. 파일 공유 기능 사용:
   - '파일 전송' 버튼 클릭
   - 전송할 파일 선택
   - 수신자 선택 또는 모두에게 전송

## 프로젝트 구조
```
src/
├── server/       # 서버 관련 클래스
├── client/       # 클라이언트 UI 및 기능 클래스
├── model/        # 데이터 모델 클래스
└── util/         # 유틸리티 클래스
```
